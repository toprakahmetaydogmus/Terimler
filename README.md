## 🎯 1. Overview
An intuitive and comprehensive glossary breaking down **100 fundamental and advanced cybersecurity concepts** into crystal-clear definitions, architectural contexts, and real-world scenarios.

### Categories:
1. **Network & Protocol Security:** Firewalls, IDS/IPS, Zero Trust, mTLS, VPN, DNS Tunneling, BGP Hijacking.
2. **Offensive Security & Red Teaming:** Kerberoasting, Pass-the-Hash, SQLi, XSS, BOLA/IDOR, Buffer Overflows.
3. **Defensive Security & Blue Teaming:** SIEM, SOC, SOAR, EDR/XDR, Threat Hunting, Sigma Rules, MITRE ATT&CK.
4. **Cryptography & PKI:** Asymmetric Encryption, PKI, CA, Hash Functions, Quantum Cryptography, Perfect Forward Secrecy.
5. **Cloud & DevSecOps:** IAM, CIS Benchmarks, Container Escape, eBPF, SAST/DAST, Software Supply Chain.
